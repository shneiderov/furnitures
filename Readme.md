1. Преимущественно используются шканты Ø8х35мм. Присадка под **шкант Ø8х35** для стыка пласть-торец: торец -  25мм, пласть - 11мм; для стыка торец-торец оба торца по 18мм.

2. Присадка под минификс для плиты 16мм: эксцентрик Ø15х12мм (отступ от кромки 34мм), шток Ø8х34мм. Для плиты 18мм: эксцентрик Ø15х13мм (отступ от кромки 34мм), шток Ø8х34мм.

4. Толщина кромки: корпус - 2мм, фасады - 2мм, съёмные полки - 0,8мм.
Присадка под направляющие шариковые AQ 45х500мм на корпусе (от фасада) Ø3х2мм (под шурупы 3,5х12мм по аналогии с петлёй мебельной): 37мм, 101мм, 229мм, 325мм.

5. Присадка под направляющие шариковые AQ 45х500мм на ящике (от фасада) Ø3х2мм (под шурупы 3,5х12мм по аналогии с петлёй мебельной): 50мм, 242мм, 370мм.

6. Присадка под ответную планку петли мебельной: отступ от фасада 37мм, отступ от центра симметрично по 16мм, отверстия Ø3х2мм (под шурупы 3,5х12мм).

7. Присадка под дверные ручки сквозная Ø5мм.

8. Наименование деталей `X-[YD]-KD[/LD]`, где `X` - номер (число) обособленной мебельной единицы (обязательно), `YD` - буквенно-цифровое обозначение секции в составе мебельной единицы (необязательно), `KD` - буквенно-цифровое обозначение детали в составе секции (обязательно, здесь `K` - обычно `H`-для горизонтальных деталей, `V`-для вертикальных). Примеры наименования: 1-H2 (обычно вторая горизонтальная деталь первой мебельной единицы) или 2-2-V1 (обычно первая вертикальная деталь второй секции второй мебельной единицы).

9. Присадка под полкодержатель Ø5х7мм.

10. Присадка под петли: Петля 165° накладная 45мм h0: чашка Ø35х13мм (отступ от кромки 22мм для зазора 2мм)."
